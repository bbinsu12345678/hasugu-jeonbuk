## 2. 전북하수구에 즉시 붙일 만한 항목 (우선순위)

### 🥇 1순위 — DataLab 검색 트렌드 API (**모니터링**)

**이유**: 우리 사이트의 타겟 키워드(변기막힘·하수구막힘·24시배관·전주변기막힘 등)가 네이버 사용자들 사이에서 언제·어디서·누가 찾는지 실시간 파악. 키워드 · 콘텐츠 · 블로그 발행 시점 결정에 필수.

**데이터**:
- 지역별 검색 볼륨 (전주 > 군산 > 익산 > ...)
- 월별 추이 (계절 · 장마 · 한파 피크)
- 연령대 · 성별 (30~50대 여성 주부 vs 20~40대 남성 자취생)
- 경쟁 키워드 비교 ("변기뚫는법" vs "변기막힘업체")

**구현**:
- `scripts/naver-datalab-collector.py` — 주 1회 자동 수집 → `data/trends.json`
- 결과를 홈 Hero `hub-eyebrow` 에 "이번 주 검색 급증 키워드" 표시 (SEO 동적 신호)

**비용**: 무료 · 일 1,000 호출 한도 · 키워드 5개씩 묶어 호출

---

### 🥈 2순위 — 검색 API (**실시간 경쟁사 모니터링**)

**이유**: `/search/webkr?query=전주+하수구막힘` 호출로 네이버 웹문서 검색 결과 100건 수집. **우리 사이트 순위 + 경쟁사 신규 진입 + 중복 콘텐츠 탐지** 가능.

**활용**:
- 주 1회 14 시/군 × 8 서비스 = 112 키워드 순위 모니터링
- `scripts/naver-rank-tracker.py` → `docs/RANK_LOG_{yyyymmdd}.json`
- 추가: 블로그 검색 API 로 신뢰도 높은 블로거 리스트 뽑고 제휴 문의

**비용**: 무료 · 일 25,000 호출 한도

---

### 🥉 3순위 — 지도 API (**사용자 경험**)

**이유**: 각 시/군 페이지 · 블로그 페이지에 "서비스 가능 지역" 지도 삽입. 실시간 길찾기는 불필요, **정적 지도 이미지 (Static Map)** 로 충분.

**구현**:
- 각 시/군 Hero 에 `<img src="https://naveropenapi.apigw.ntruss.com/map-static/v2/raster?center={LAT},{LNG}..." />`
- 14 시/군 좌표는 `regions.ts` 에 이미 있음 (`scripts/inject-exif.py` 참조)

**비용**: 무료 · 월 200,000 호출

---

### 🎖️ 4순위 — 서치어드바이저 자동 제출 (**색인 가속**)

**이유**: 배포마다 네이버 SA 수동 재제출 번거로움. 자동화 스크립트로 **빌드 완료 직후 sitemap 변경 알림 자동 전송**.

**구현**:
- `scripts/naver-sitemap-submit.py` (기존 banana-app 프로젝트에 유사 로직 있음, 완전 분리 구현 필요)
- Vercel 빌드 후크에서 post-deploy 로 자동 호출
- RSS 재제출 동시 진행

**비용**: 무료 · 제한 없음

---

### 🎖️ 5순위 — 검색광고 API (**키워드 인텔리전스**)

**이유**: 네이버 검색광고 계정 보유 시, 키워드별 **월 예상 검색량 · 클릭수 · 입찰가** 데이터 접근 가능. 블로그 제목 · H2 · URL 접미사 선정의 근거.

**활용**:
- 60개 URL 접미사 중 실제 트래픽 0인 것 솎아내기 (도어웨이 리스크↓)
- 고볼륨 신규 키워드 발견 시 새 접미사 추가

**비용**: 네이버 검색광고 계정 필요 (광고 미집행 시에도 계정 생성 가능)

---

### 🔄 6순위 — 톡톡 오픈채팅 API (**상담 자동화**)

**이유**: 현재 카카오톡 오픈채팅만 지원. 네이버 톡톡 연결 시 검색 결과에서 바로 상담 버튼 노출.

**구현**:
- 네이버 톡톡 계정 생성 → 자동 응답 FAQ 등록 (변기막힘·싱크대·출장비 등 15개)
- `layout.tsx` 에 `<a href="https://talk.naver.com/ct/...">` 연결

**비용**: 무료 · 자동 응답 무제한

## 4. 보안 · 제한사항

1. **API 키는 서버사이드만** — 검색 API · DataLab 은 클라이언트 호출 시 키 노출 위험. Next.js 정적 export 에서는 **빌드 타임에 서버에서 호출 → JSON 캐싱** 방식으로 클라이언트 번들에 키 유출 X.
2. **호출 한도 모니터링** — 일 25,000 초과 시 다음 날까지 차단. 자동화 스크립트에 `--dry-run` · `--limit=100` 옵션 필수.
3. **저작권** — 네이버 블로그·카페 검색 결과의 **본문 크롤링은 금지**. URL · 제목 · 작성일 까지만 수집.
4. **robots.txt** — 네이버 Yeti 봇 Allow 상태 재확인 (현재 OK).
